# Components index
Pick the file(s) matching what's on screen or what the user asked about. Each file is self-contained: all component-specific principles in full + pointers to core global checks.

- **buttons.md** — Buttons & actions (16 principles). Clickable actions: buttons, button groups, links styled as buttons, icon buttons, CTAs.
- **cards.md** — Cards (31 principles). Containers with background, border or shadow grouping related content (product, profile, pricing, feed items, metric tiles).
- **forms.md** — Forms & inputs (21 principles). Text inputs, selects, checkboxes, radios, labels, validation, multi-step forms, settings pages, login/signup.
- **tables-lists.md** — Tables & lists (23 principles). Data tables, list views, feeds, row-based collections, spec sheets, search results.
- **navigation.md** — Navigation (13 principles). Top nav, sidebars, tabs, breadcrumbs, dropdown menus, steppers.
- **headers-hero.md** — Headers & hero sections (25 principles). Page titles, section headings, landing-page heroes, marketing sections, feature rows.
- **dashboards-stats.md** — Dashboards & stats (11 principles). Metric tiles, KPIs, charts, summary panels, data-dense overview screens.
- **modals.md** — Modals & overlays (9 principles). Dialogs, confirmations, popovers, drawers, anything floating above the page.
- **empty-states.md** — Empty states (7 principles). Screens or sections with no data yet: first-run, zero results, cleared lists.
- **alerts-badges.md** — Alerts & badges (9 principles). Alerts, banners, toasts, status pills, tags, 'NEW' labels, inline notices.
- **avatars-images.md** — Avatars & images (8 principles). Photos, avatars, thumbnails, icons, illustrations, screenshots, user-uploaded media.
- **long-text.md** — Long-form text (13 principles). Paragraphs, articles, docs, descriptions, blog posts, help content.
